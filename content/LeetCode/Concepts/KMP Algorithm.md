## KMP 解決的問題

就是字符串匹配的問題，例：

- **文本串：**`aabaabaaf`
- **模式串：**`aabaaf`

**問：文本串中有沒有出現過模式串之類的問題**

## 前綴表的由來

前綴表是用來回溯的。它記錄了當模式串與文本串不匹配時，模式串應該從哪裡開始重新進行匹配。
為了清楚地了解前綴表的由來，我們舉一個例子：
**要在文本串：`aabaabaafa` 中尋找是否出現過模式串：`aabaaf`。**
請記住文本串和模式串的角色，這對理解下文非常重要，否則很容易一頭霧水。
如動畫所示：
![[KMP-1.gif]]
可以看出，在文本串中，第六個字元 `b` 與模式串的第六個字元 `f` 不匹配了。如果使用暴力匹配法，一旦發現不匹配，此時就必須從頭開始重新匹配。
但如果使用前綴表，就不會從頭來過，而是從上次已經匹配的部分繼續開始。在這個例子中，它會跳到模式串中的第三個字元 `b`，從這裡繼續進行匹配。

這時問題來了：**前綴表是如何做到記錄的呢？**

首先要了解，前綴表的任務是在當前位置匹配失敗時，找到之前已經匹配過的長度，然後從那個位置重新開始匹配。這也意味著，在某個字元失配時，前綴表會告訴你下一步的匹配中，模式串應該跳到哪個位置。
那麼，什麼是前綴表呢？**前綴表記錄了在每一個索引 i 之前（包含 `i`）的子字串中，最長相同前綴和後綴的長度。**

## 前綴與後綴

- **前綴是指不包含最後一個字元的所有從第一個字元開始的連續子字串。**
- **後綴是指不包含第一個字元的所有以最後一個字元結尾的連續子字串。**

以 `ababa` 為例

- 所有前綴
`a、ab、aba、abab`
- 所有後綴
`a、ba、aba、baba`

## 最長相等前後綴

**前缀表要求的就是相同前后缀的长度。**

## 使用前綴表的匹配過程

回顧一下，剛才的匹配過程在索引 5 的地方遇到了不匹配，模式串指向的是 `f`，如圖所示：
![[KMP-2.png|500]]
然後，我們就跳到了索引 2，模式串指向 `b`，繼續進行匹配，如圖所示：
![[KMP-3.png|500]]
**在索引 5 之前這部分的字串（也就是子字串 `aabaa`）的最長相等前綴與後綴，是子字串 `aa`。因為我們找到了最長相等的前綴和後綴，而匹配失敗的位置正好在後綴子字串之後，那麼我們只要找到與其相同的前綴的後面，從那裡重新開始匹配即可。**
因此，前綴表賦予了我們一個能力：當前位置匹配失敗時，它會告訴我們應該跳回到之前已經匹配過的地方，而不是從頭來過。

## 如何計算前綴表

如圖：
![[KMP-4.png|500]]
長度為前 1 個字元的子字串 `a`，最長相同前後綴的長度為 0。
![[KMP-5.png|500]]
長度為前 2 個字元的子字串 `aa`，最長相同前後綴的長度為 1。
![[KMP-6.png|500]]
長度為前 3 個字元的子字串 `aab`，最長相同前後綴的長度為 0。

以此類推：
長度為前 4 個字元的子串 `aaba`，最長相同前後綴的長度為 1。
長度為前 5 個字元的子串 `aabaa`，最長相同前後綴的長度為 2。
長度為前 6 個字元的子串 `aabaaf`，最長相同前後綴的長度為 0。

那麼，求得的最長相同前後綴的長度就是對應前綴表的元素，如圖所示：
![[KMP-7.png]]
可以看出，模式串與前綴表對應位置的數字表示的就是：**在索引 `i` 之前（包括 `i`）的子字串中，最長相同前綴和後綴的長度。**
再來看一下如何利用前綴表，找到當字元不匹配時，指標應該移動到的位置。如動畫所示：
![[KMP-8.gif]]
找到不匹配的位置後，此時我們需要看它前一個字元所對應的前綴表數值是多少。
為什麼要看前一個字元的前綴表數值呢？因為我們要找的是前面那段已匹配的子字串，其最長相同的前綴和後綴。
前一個字元的前綴表數值是 2，所以把索引移動到索引 2 的位置，繼續進行匹配。你可以再反覆觀看上面的動畫。
最後就在文本串中，找到了和模式串匹配的子字串了。

## `next` 數組

雖然圖片中以及 [講解](https://programmercarl.com/0028.%E5%AE%9E%E7%8E%B0strStr.html#%E6%80%9D%E8%B7%AF) 有講到把 `next` 數組減一或右移的操作，但我還是覺得先不要變動 `next` 數組來看就好。
![[KMP-9.gif]]
圖片中是已經減過 1 的數組，在心中把他加回 1 就好

```cpp
void getNext(int* next, const string& s) {
    int j = -1;
    next[0] = j;
    for(int i = 1; i < s.size(); i++) { // 注意 i 從 1 開始
        while (j >= 0 && s[i] != s[j + 1]) { // 前後綴不相同了
            j = next[j]; // 向前回退
        }
        if (s[i] == s[j + 1]) { // 找到相同的前後綴
            j++;
        }
        next[i] = j; // 將 j（前綴的長度）給 next[i]
    }
}
```
