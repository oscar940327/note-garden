## KMP 解決的問題

KMP 用來解決字串比對問題，例如：

- **主字串：**`aabaabaaf`
- **模式字串：**`aabaaf`

**問：主字串中是否出現過模式字串？**

## 前綴表的由來

前綴表用來回溯。當模式字串與主字串比對失敗時，它會記錄模式字串應從哪裡重新開始比對。
為了清楚地了解前綴表的由來，我們舉一個例子：
**要在主字串 `aabaabaafa` 中尋找模式字串 `aabaaf`。**
請記住主字串和模式字串各自代表什麼，這對理解下文很重要。
如動畫所示：
![[KMP-1.gif]]
可以看出，主字串中的第六個字元 `b` 與模式字串中的第六個字元 `f` 不相符。使用暴力比對法時，一旦發現不相符，就必須從頭重新比對。
使用前綴表則可以從上次已比對的部分繼續，不必從頭開始。在這個例子中，模式字串會跳到第三個字元 `b`，再從那裡繼續比對。

這時問題來了：**前綴表是如何做到記錄的呢？**

前綴表的任務是在目前位置比對失敗時，找出先前已成功比對的長度，再從適當的位置重新開始。也就是說，當某個字元不相符時，前綴表會告訴我們模式字串下一步應跳到哪裡。
那麼，什麼是前綴表呢？**前綴表記錄了在每一個索引 i 之前（包含 `i`）的子字串中，最長相同前綴和後綴的長度。**

## 前綴與後綴

- **前綴是指不包含最後一個字元的所有從第一個字元開始的連續子字串。**
- **後綴是指不包含第一個字元的所有以最後一個字元結尾的連續子字串。**

以 `ababa` 為例

- 所有前綴
`a、ab、aba、abab`
- 所有後綴
`a、ba、aba、baba`

## 最長相等前後綴

**前綴表記錄的是最長相同前綴與後綴的長度。**

## 使用前綴表進行比對

回顧剛才的比對過程：在索引 5 遇到不相符時，模式字串指向 `f`，如圖所示：
![[KMP-2.png|500]]
接著，索引跳到 2，模式字串指向 `b`，並從此處繼續比對，如圖所示：
![[KMP-3.png|500]]
**索引 5 之前的字串，也就是子字串 `aabaa`，其最長相同前綴與後綴都是 `aa`。比對失敗的位置在已比對後綴之後，因此可以找到與該後綴相同的前綴，並從前綴之後繼續比對。**
因此，前綴表能在目前位置比對失敗時，指出應跳回的位置，避免每次都從頭開始。

## 如何計算前綴表

如圖：
![[KMP-4.png|500]]
長度為前 1 個字元的子字串 `a`，最長相同前後綴的長度為 0。
![[KMP-5.png|500]]
長度為前 2 個字元的子字串 `aa`，最長相同前後綴的長度為 1。
![[KMP-6.png|500]]
長度為前 3 個字元的子字串 `aab`，最長相同前後綴的長度為 0。

以此類推：
前 4 個字元組成的子字串 `aaba`，最長相同前綴與後綴的長度為 1。
前 5 個字元組成的子字串 `aabaa`，最長相同前綴與後綴的長度為 2。
前 6 個字元組成的子字串 `aabaaf`，最長相同前綴與後綴的長度為 0。

那麼，求得的最長相同前後綴的長度就是對應前綴表的元素，如圖所示：
![[KMP-7.png]]
可以看出，模式字串與前綴表中對應位置的數值，表示索引 `i`（含）之前的子字串中，最長相同前綴與後綴的長度。
接著看看如何利用前綴表，找出字元不相符時指標應移動到的位置，如動畫所示：
![[KMP-8.gif]]
找到比對失敗的位置後，要查看前一個字元對應的前綴表數值。
這個數值代表前面已比對子字串中最長相同前綴與後綴的長度。
前一個字元的前綴表數值是 2，因此將索引移到 2，繼續比對。可以反覆觀看上方動畫。
最後便能在主字串中找到與模式字串相符的子字串。

## `next` 陣列

雖然圖片和[講解](https://programmercarl.com/0028.%E5%AE%9E%E7%8E%B0strStr.html#%E6%80%9D%E8%B7%AF)有提到將 `next` 陣列的值減一或右移，但我建議先不要調整 `next` 陣列，直接理解原始數值。
![[KMP-9.gif]]
圖片中的陣列已經先減 1；閱讀時在心中把它加回 1 即可。

```cpp
void getNext(int* next, const string& s) {
    int j = -1;
    next[0] = j;
    for(int i = 1; i < s.size(); i++) { // 注意 i 從 1 開始
        while (j >= 0 && s[i] != s[j + 1]) { // 前後綴不相同了
            j = next[j]; // 向前回退
        }
        if (s[i] == s[j + 1]) { // 找到相同的前後綴
            j++;
        }
        next[i] = j; // 將 j（前綴的長度）給 next[i]
    }
}
```
