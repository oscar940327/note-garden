### 🧠 核心思路

1. 先遍歷前兩個數組，把前兩個數組可能產生的值放進 `maps` 裡面
2. 再遍歷後兩個數組，看式子成不成立 `0-(c+d) = target` `註解 1`
> [!note]- **註解**
> 註解 1：因為 `(a+b)+(c+d)=0` => `(a+b)=0-(c+d)`
3. 如果有等於，`count += map[target]`，因為要把出現過是 `target` 的值的次數都加起來，真的不懂的話再看一次影片。

```cpp
unordered_map<int, int> map;
for(a : A){
    for(b : B){
        map[a+b]++;
    }
}
for(c : C){
    for(d : D){
        target = 0-(c+d);
        if(map.find(target) != map.end()){
            count += map[target];
        }
    }
}
return count;
```
